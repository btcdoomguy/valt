## Color

| Role | Resource / Value | Usage |
|------|------------------|-------|
| Dominant (60%) | `Background800Brush` | Page/section background, `Expander` background |
| Secondary (30%) | `Background900Brush` | Chart surfaces, inner containers, `Border` backgrounds |
| Accent (10%) | `Accent500Brush` / `Accent400Brush` | Section header icon; **Liquidation distance line** stroke and fill; highlight elements that need attention |
| Secondary data | `Secondary500Brush` (#0566e9) | **Loan cost stacked-bar series** fill — distinct from accent line and existing green/red semantics |
| Destructive / Danger | `SemanticNegative500Brush` / `Debt` brush | Danger zone for liquidation distance (>75 LTV points); destructive/error states only |
| Warning | `SemanticWarning500Brush` / `Warning` brush | Warning zone for liquidation distance (≤75 LTV points) |
| Positive | `SemanticPositive500Brush` / `Credit` brush | Safe zone for liquidation distance (≤60 LTV points) |
| Text primary | `Text200Brush` | Headings, empty-state headings, legend text |
| Text secondary | `Text400Brush` | Body text, axis labels, loading text |
| Text muted | `Text500Brush` | Section descriptions, de-emphasized labels |
| Grid/separator | `Background700Brush` | Chart grid lines, borders, separators |

Accent reserved for:
- Section header icon for the new "Loans & Leverage Reports" expander.
- Liquidation distance trend line stroke and fill (consistent with `StackVelocityChartData` accent usage for trend lines).
- No other UI elements in this phase use accent.

Color rule for liquidation distance line:
- The line/area color is driven by the **current worst-case distance** using the same thresholds as `DashboardDataBrushes.ForLtv` (reusing `TransactionGridResources.Credit` / `Warning` / `Debt` brushes):
  - `distance > 15` percentage points (LTV ≤ 60) → green / safe
  - `distance > 0` and `≤ 15` percentage points (LTV ≤ 75) → yellow / warning
  - `distance ≤ 0` or LTV > 75 → red / danger
- If LiveCharts per-segment coloring is impractical, the entire line is colored with the current risk band; this is the pragmatic fallback noted in 42-RESEARCH.md R5.

## UI Structure & Placement

### Location
- Add a new `Expander` with `Classes="section"` **inside the monthly-totals group `Border`** (`ReportsView.axaml` lines 249–667), **after the Stack velocity expander** (line 582) and **before the Categories expander** (line 669).
- The section shares the existing `DateCalendarSelector` at the top of the monthly-totals group (lines 255–263); no second date picker is added.

### Section layout
- `Expander` header: Material icon + `Reports_LoanReports_Title`.
- Inside the expander: `StackPanel` containing:
  1. Description `TextBlock` with `Reports_LoanReports_CostDescription`.
  2. Cost chart container (`Grid` with `MinHeight="400"`):
     - Loading `TextBlock` when `IsLoanReportsLoading`.
     - `Border` (chart surface) with `CartesianChart` bound to `LoanCostChartData` when not empty.
     - `Border.hint-box` when `IsLoanReportsEmpty`.
  3. Description `TextBlock` with `Reports_LoanReports_DistanceDescription`.
  4. Distance chart container (`Grid` with `MinHeight="400"`):
     - Same loading/empty/error pattern as cost chart.

### Visibility states
- **Whole section visibility**: `IsLoanReportsVisible` is `true` only when the user has at least one active BTC-backed loan; otherwise the expander is hidden (consistent with existing `IsBtcLoansVisible` / `IsLeveragePositionsVisible` dashboard panels). [Source: 42-CONTEXT.md phase boundary; ROADMAP Phase 42 success criterion 3.]
- **Within-section empty state**: `IsLoanReportsEmpty` is `true` when active loans exist but the selected date range yields no data (e.g., loans were created after the range, or all months have zero cost/distance). The chart is replaced by a `hint-box` empty message.
- **Error state**: `IsLoanReportsError` displays a `hint-box` error message (reuse `Reports_BtcMetrics_ErrorTitle` / `Reports_BtcMetrics_ErrorBody` if no new keys are added, or use the new keys above).
- **Loading state**: `IsLoanReportsLoading` shows the standard `Loading` text block centered in the chart area.

## Charts

### 1. Combined monthly interest + fees cost — stacked bar chart
- **Type**: `CartesianChart` with a single `StackedColumnSeries<double>` (per D-02: one combined series, not separate interest and fees series).
- **Data class**: `LoanCostChartData` (new), modeled on `FixedVsVariableChartData`.
- **X-axis**: months, formatted `MMM yyyy`.
- **Y-axis**: fiat amount in the user's main currency, formatted with `CurrencyDisplay.FormatFiat`.
- **Color**: `Secondary500Brush` (blue #0566e9) for the column fill — distinct from the accent distance line and from green/red semantic colors.
- **Legend**: single series name `Interest + fees`.
- **Tooltip**: show month and combined cost formatted in main currency.
- **Height**: 400 (matching existing charts).

### 2. Worst-case liquidation distance — line chart
- **Type**: `CartesianChart` with a `LineSeries<ObservablePoint>`.
- **Data class**: `LiquidationDistanceChartData` (new), modeled on `StackVelocityChartData`.
- **X-axis**: months, formatted `MMM yyyy`.
- **Y-axis**: LTV percentage points (`LiquidationLtv - CurrentLtv`), clamped to ≥ 0.
- **Color**: accent stroke/fill with alpha fill; risk band color applied as described in Color section.
- **Legend**: single series name `Closest to liquidation`.
- **Tooltip**: show month, distance value, and closest loan name (from `LiquidationDistanceMonthDto.ClosestLoanName`).
- **Height**: 400.

| visibility | Section presence gated by active loans | ✅ covered | `IsLoanReportsVisible` is set from the query result (`HasActiveLoans`) and observed by the `Expander` `IsVisible` binding. |
