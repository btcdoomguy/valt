## Explicit Assumptions (EDGE_ABSENT unresolved items)

- **LON-01 unclassified**: The meaning of "total interest/fees paid" is taken as lifetime carrying cost from the loan start through today, split by calendar month. This matches D-01.
- **LON-02 boundary**: A loan contributes to month M only if its effective snapshot at month-end M has Active status. Mid-month creation/repayment means no contribution for that month per D-08. Tests verify one step on either side of these thresholds.
- **LON-02 precision**: Interest accrual uses simple interest `TotalBorrowed * Apr / 365` rounded to 2 decimals per existing BtcLoanDetails math. Distance is rounded to 2 percentage points. Currency conversion returns 0 when a required rate is missing.
