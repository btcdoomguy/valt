## Panel Layout & Interaction

### Placement

Add two new `Expander` sections after the existing **Fixed vs variable expenses** section and before the **Categories** section in `ReportsView.axaml` (D-16).

### 1. Sats earned & spent panel

- **Header icon:** `currency_bitcoin` (`\uEBC5`) — Material Symbols Outlined.
- **Header title:** `{x:Static lang:language.Reports_BtcMetrics_Title}`.
- **Toggle row** (centered above the chart):
  - TextBlock `"Monthly"` → `ToggleSwitch` `IsChecked="{Binding IsBtcMetricsCategoryView, Mode=TwoWay}"` → TextBlock `"By category"`.
  - Unchecked (default) = monthly grouped bars.
  - Checked = sats spent per category horizontal bars.
  - Font size `FontSizeSmall`, foreground `Text300Brush`, spacing 8px between label and switch.
- **Chart container:**
  - `Border` with `Background="{DynamicResource Background900Brush}"`, `BorderBrush="{DynamicResource Background700Brush}"`, `BorderThickness="1"`, `CornerRadius="4"`, `Padding="10"`, `MinHeight="400"`.
  - Monthly view: `CartesianChart` `Height="400"`, `LegendPosition="Top"`, grouped columns for Earned/Spent.
  - Category view: `ScrollViewer` `MaxHeight="600"`, `VerticalScrollBarVisibility="Auto"`, containing a horizontal bar chart colored by category icon color.
- **Empty/error state:** centered `Border` with `hint-box` style containing the documented heading/body copy.

### 2. Stack velocity panel

- **Header icon:** `speed` (`\uE9E4`) — Material Symbols Outlined.
- **Header title:** `{x:Static lang:language.Reports_StackVelocity_Title}`.
- **Chart container:** same border style as above, `MinHeight="400"`.
- **Chart:** `CartesianChart` `Height="400"`, `LegendPosition="Top"`, single line series for net sats per month.
- **Empty/error state:** same `hint-box` pattern as above.

### Formatting rules

- All BTC-denominated amounts render via `CurrencyDisplay.FormatAsBitcoin(sats / 100_000_000m)` (app-standard grouped BTC format, e.g. `1.23 456 789 BTC`).
- Y-axis labeler and data labels use the same formatter.
- Negative velocity values render with leading `-` using the same formatter.

Source: `40-CONTEXT.md` D-10, D-11, D-13, D-14, D-15; existing `CurrencyDisplay` and chart-data patterns.
