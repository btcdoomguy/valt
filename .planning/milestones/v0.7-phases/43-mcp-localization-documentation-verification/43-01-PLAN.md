## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → MCP server | Untrusted AI assistant input crosses into the application; MCP server is localhost-only per existing design. |
| Reports UI → user | Localized strings are shown to the user; drift or missing translations degrade UX but do not expose data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-43-01 | Information Disclosure | `GetSpendingAnalytics` MCP tool | medium | mitigate | Tool returns aggregate summary data only; MCP server runs on localhost and is documented as such. No raw transaction list exposure. |
| T-43-02 | Input Validation | `GetSpendingAnalytics` date/currency parameters | medium | mitigate | Reuse existing `DateOnly.Parse` and `FiatCurrency.GetFromCode`; wrap in try/catch and surface a clear error string to the MCP caller. |
| T-43-03 | Repudiation | MCP tool DTO shape change after release | medium | mitigate | Mark DTO shape as one-way in `reversibility`; avoid breaking property renames. |
| T-43-SC | Tampering | NuGet package installs (no new packages expected) | high | accept | No new NuGet packages are introduced in this phase; existing package restore is managed by `dotnet` and source-build validation. |
</threat_model>
