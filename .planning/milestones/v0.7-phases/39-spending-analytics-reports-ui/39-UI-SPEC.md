# Phase 39 — UI Design Contract

> Visual and interaction contract for the Spending Analytics Reports phase (SPA-01 savings rate, SPA-02 burn rate, SPA-03 fixed vs variable ratio). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Platform note:** Valt is an Avalonia 11 desktop app (FluentTheme base + custom runtime theme system), not a web/React project. The shadcn gate is not applicable. All tokens below are extracted from the existing codebase and are binding for the new panels.

## Component & Layout Inventory

All three metrics plug into the existing Reports tab (`ReportsView.axaml`), honoring tab filters (D-18) and secure-mode overlay (already tab-wide).

### 1. Burn rate card (SPA-02) — dashboard card

- **Container:** new `<Grid MinHeight="150">` inside `DashboardGridPanel`, placed after the Statistics card (default placement; planner may adjust per D-discretion).
- **Pattern:** `DashboardPanelViewModel` subclass + `DashboardData` rows, rendered by `DashboardDataUserControl` (320px card, header band `Background600Brush`, alternating `Background800/900` rows, `12,6` row padding).
- **Icon:** `whatshot` `\uE80E`.
- **Rows (day ≥ 5, D-15):** `Spent so far (this month)` → fiat; `Avg daily spend` → fiat; `Projected month-end` → fiat; `Median month (12 mo)` → fiat (reuses `StatisticsReport.MedianMonthlyExpenses`, D-13); `vs median` → signed % with tooltip, colored `CreditBase` when projection ≤ median, `DebtBase` when above.
- **Rows (days 1–4, D-15):** `Spent so far (this month)`, `Avg daily spend`, then a muted row `Projection available from day 5` (right text `—`, `Text500Brush` semantics via stale-style is NOT used; simply omit the projection rows and show the note row).
- **Loading:** centered `Loading...` TextBlock (`FontSizeMedium`, `Text400Brush`) — existing pattern, `IsBurnRateLoading` flag.

### 2. Savings rate chart (SPA-01) — new `Expander.section`

- **Placement:** new `Expander` (class `section`, `IsExpanded="True"`) after the *Monthly totals* Expander, before *Categories* (default; planner may adjust).
- **Header:** icon `savings` `&#xE2EB;` (`section-header-icon`) + title `Savings rate` (`section-header`).
- **Chart:** `CartesianChart` in the standard chart `Border` (`Background900Brush`, `Background700Brush` border 1px, `CornerRadius=4`, `Padding=10`), chart `Height="400"`, `Margin="20,10,20,10"`, `ZoomMode="None"`, `TooltipTextSize="12"`, `LegendPosition="Top"`.
- **Series (new `SavingsRateChartData`, mirrors `MonthlyTotalsChartData`):** single `LineSeries<ObservablePoint>`, stroke `#e98805` thickness 2.5, geometry fill `#ffcc88` / stroke `#ffa122` size 8, fill `#ffa122` alpha 40, `LineSmoothness=0.3`. Y-axis labeler renders `%`; X-axis `MMM yyyy` labels, `LabelsRotation=-45`, `MinStep=1`, `ForceStepToMin`.
- **Data rules surfaced visually:** zero-income months = gap in the line (D-02); negative rates shown as-is, below the zero separator (D-03); current incomplete month excluded (D-04).

### 3. Fixed vs variable chart (SPA-03) — new `Expander.section`

- **Placement:** directly after the Savings rate Expander.
- **Header:** icon `stacked_bar_chart` `&#xE9E6;` + title `Fixed vs variable expenses`.
- **Chart:** same container chrome as above, `Height="400"`. `StackedColumnSeries<double>` per month: **Fixed** `#0566e9`, **Variable** `#ffa122`, legend top (`Fixed`, `Variable`). X-axis `MMM yyyy`; Y-axis fiat labeler (or % — planner picks one axis unit and applies it consistently; default: fiat totals stacked, tooltip shows both fiat and % share).
- **Empty state (no fixed expenses registered at all, D-10):** replace chart with `Border.hint-box` containing the hint copy (see Copywriting). Do NOT render an empty chart.
- **Data rules surfaced visually:** months with expenses but no bound fixed transactions render a full-height Variable bar (D-08); current month excluded (D-09).

### Reused assets (do not restyle)

`DashboardGridPanel` (+ `IsLargeToRowSpanConverter`), `DashboardData`/`RowItem`/`TooltipContent`, `DashboardPanelViewModel.SetData/SetError`, `DateCalendarSelector`, `Border.hint-box`, `Loading` string, `CurrencyDisplay.FormatFiat`, `TransactionGridResources.Credit/Debt` (+/- colors), `FetchAllReportsAsync` parallel fetch + per-panel `Is*Loading` flags + 300ms filter debounce.

## Interaction Contract

- **Loading:** per-panel `Is*Loading` flags → centered `Loading...` (`FontSizeMedium`, `Text400Brush`) over a `MinHeight` placeholder (150 card / 400 chart), fetched in parallel inside `FetchAllReportsAsync`.
- **Filters:** all three panels react to the existing Reports filters (accounts, categories, date range) with the established 300ms debounce (D-18). No new filter UI.
- **Stale state:** not applicable (metrics computed from local data; the `stale` card style is reserved for remote indicator caches).
- **Secure mode:** covered by the existing tab-level overlay; no panel-specific handling.
- **Tooltips:** dashboard rows use `TooltipContent` (300ms delay); chart tooltips 12px Inter on `#333333` background.
- **Theming:** every brush is a `DynamicResource`; new chart-data classes copy the hex constants from `MonthlyTotalsChartData` (they are the chart-side mirror of the Default palette).
