<objective>
Expand the proven tracer filter (plan 01, MonthlyTotals only) to every remaining report income/expense aggregation, and close the HIGH-severity stale-report-cache gap (Pitfall 1): today `ReportDataProviderFactory` invalidates only on transaction-count change, so a flag toggle — an edit with unchanged count — would serve stale reports. Reports must reflect a toggle immediately without app restart.

Purpose: The feature's entire user value is changing a number the user checks immediately; a count-based cache silently defeats it. The fix is also the phase's only new wiring (no direct analog in the codebase), so it gets dedicated tests.
Output: All income/expense report buckets honor the flag; explicit cache invalidation on every transaction save/delete.
</objective>
