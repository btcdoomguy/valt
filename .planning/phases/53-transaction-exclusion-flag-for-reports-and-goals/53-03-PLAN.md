Apply the exclusion flag to every goal progress calculation, keeping each calculator's paired methods (progress math + contributing-transactions rows) in verbatim lockstep so the Goal Summary modal can never disagree with the progress bar. Output: All 9 income/expense/transfer-based goal strategies filter the flag; reconciliation (progress == final running total) holds under exclusion.
</objective>
