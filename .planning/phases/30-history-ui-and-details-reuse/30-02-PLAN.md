<objective>
Wire the active Assets view to the MarkAssetAsSold command. This plan replaces the old "Sell" context-menu action with a "Mark as Sold" flow that records a sale date, optionally records a proceeds transaction, and refreshes the main view so sold assets appear in the History screen.

Purpose: Without this flow, users cannot create sold assets from the UI and the History screen would remain empty. It also closes the ASSET-01 UI gap.
Output: DateSoldPrompt modal and the MarkAssetAsSold command integration.
</objective>
