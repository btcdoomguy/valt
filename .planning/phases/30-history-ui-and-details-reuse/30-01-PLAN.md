## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-01 | Destruction | Restore Asset command | mitigate | RestoreAsset dispatches UndoAssetSaleCommand only; never calls DeleteAssetCommand. Per D-15/D-16. |
| T-30-02 | Tampering | Totals refresh after undo | mitigate | On successful undo, WeakReferenceMessenger.Default.Send(new AssetSummaryUpdatedMessage()) is called before CloseWindow. |
| T-30-03 | Information Disclosure | Sold-asset list visibility | accept | Sold assets are user-owned data; the History modal is only accessible from the authenticated application. |
| T-30-04 | Denial of Service | DataGrid sort lock | mitigate | CanUserSortColumns="False" prevents user from accidentally reordering the query-sorted list. |
| T-30-SC | Tampering | Source file creation | mitigate | No new packages are installed; all new files are hand-written C#/XAML within the repository. |
</threat_model>
