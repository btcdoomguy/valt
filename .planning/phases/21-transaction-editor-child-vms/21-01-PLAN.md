<objective>
Split `TransactionEditorViewModel` into a lightweight coordinator parent plus three per-transfer-type child VMs (`Debt`, `Credit`, `Transfer`), each rendered through a `ContentControl` `DataTemplate`, while preserving the existing visual behavior, validation, and keyboard shortcuts.

Purpose: This is the first wave of VM-CHILD-01; it reduces the modal's ViewModel complexity by moving mode-specific form state and validation into focused child VMs.
Output: Refactored `TransactionEditorViewModel`, new child VMs/views, updated parent XAML, passing tests, and working design-time support.
</objective>
