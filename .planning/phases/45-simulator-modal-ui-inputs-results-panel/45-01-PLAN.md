<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → ViewModel | Local numeric/date input crosses from user to app logic. |
| ViewModel → Core calculator | Input record passed to pure static calculator; no persistence or network. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-01 | Tampering | Invalid numeric/date input in ViewModel | medium | mitigate | Recalculate validates inputs with decimal.TryParse and date range checks before calling Core; invalid state silently clears results per 45-UI-SPEC. |
| T-45-02 | Denial of Service | Null or zero BTC price causing divide-by-zero or NaN sat values | medium | mitigate | IsBtcPriceAvailable hides sat TextBlocks when RatesState.BitcoinPrice is null or zero; conversion basis shows fallback copy. |
| T-45-03 | Information Disclosure | Loan parameters visible in UI | low | accept | Data is local and ephemeral; no persistence or network transmission. |
| T-45-SC | Tampering | Package installs | n/a | n/a | No new NuGet packages are installed in this phase; not applicable. |
</threat_model>
