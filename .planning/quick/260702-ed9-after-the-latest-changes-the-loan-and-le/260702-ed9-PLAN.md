# Quick Task 260702-ed9: Restore Loan and Leverage panels in Assets tab

## Problem

After the BTC-collateral leveraged positions feature (beda261), existing fiat-collateral leveraged positions whose symbol starts with BTC and use LivePrice are incorrectly loaded as BTC-collateral in the Manage Asset modal. This hides the fiat-collateral input panel (Collateral, Leverage, Position Size) and shows the BTC-collateral panel with zeroed values, making the leverage panel appear missing.

Root cause: `AssetFormBuilder.LoadFromDto` sets `IsBitcoinUnderlyingAsset` using both the collateral type AND a symbol heuristic:

```csharp
IsBitcoinUnderlyingAsset: isBtcCollateral || (priceSource == AssetPriceSource.LivePrice && symbol.StartsWith("BTC", ...))
```

The symbol heuristic treats every fiat-collateral BTC position as BTC-collateral.

## Tasks

1. **Fix `AssetFormBuilder.LoadFromDto`**
   - File: `src/Valt.UI/Services/AssetFormBuilder.cs`
   - Change `IsBitcoinUnderlyingAsset` to depend only on `isBtcCollateral` (`dto.CollateralAssetTypeId == (int)LeveragedPositionCollateralAssetType.Btc`).

2. **Update existing test**
   - File: `tests/Valt.Tests/UI/Services/AssetFormBuilderTests.cs`
   - `LoadFromDto_LeveragedPosition_RoundTripsValues` currently expects `IsBitcoinUnderlyingAsset = true` for a fiat-collateral BTC-PERP position. Update expectation to `false`.
   - Add a test verifying a true BTC-collateral position sets `IsBitcoinUnderlyingAsset = true`.

3. **Run tests**
   - Run `dotnet test --filter "FullyQualifiedName~AssetFormBuilderTests"` to verify the fix.
   - Run `dotnet build Valt.sln` to ensure no regressions.

## Verification

- Fiat-collateral leveraged positions with BTC symbol load with `IsBitcoinUnderlyingAsset = false`.
- Manage Asset modal shows Collateral/Leverage/Position Size rows for those positions.
- BTC-collateral leveraged positions still load with `IsBitcoinUnderlyingAsset = true` and show contract/collateral-BTC rows.
- All AssetFormBuilder tests pass.
