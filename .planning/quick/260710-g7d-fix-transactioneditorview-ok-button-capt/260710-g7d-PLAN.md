# Quick Task 260710-g7d: Fix TransactionEditorView OK Button Caption

## Goal

Make the OK button label on `TransactionEditorView` context-aware:
- Show **Add Transaction** when adding a new debt/credit transaction.
- Show **Save Transaction** when editing an existing debt/credit transaction.
- Existing transfer labels (Create Transfer / Save Transfer) remain unchanged.

## Tasks

1. **Add localization resource**
   - Add `TransactionEditor_CreateTransaction` to `src/Valt.UI/Lang/language.resx` (value: `Add Transaction`).
   - Add the same key to `src/Valt.UI/Lang/language.pt-BR.resx` (value: `Adicionar transação`).
   - Add the same key to `src/Valt.UI/Lang/language.es.resx` (value: `Agregar transacción`).
   - Add the generated property to `src/Valt.UI/Lang/language.Designer.cs`.

2. **Update ViewModel logic**
   - In `src/Valt.UI/Views/Main/Modals/TransactionEditor/TransactionEditorViewModel.cs`, change `OkButtonLabel` so that non-transfer transactions use `TransactionEditor_CreateTransaction` when `_transactionId` is null and `TransactionEditor_SaveTransaction` otherwise.

3. **Update tests**
   - In `tests/Valt.Tests/UI/Screens/TransactionEditorViewModelTests.cs`, rename/update `TransactionEditorViewModel_OkButtonLabel_ShouldBeSaveTransactionForDebt` to assert the new add-mode label.
   - Add a test for edit mode that sets a transaction ID and asserts `Save Transaction`.

4. **Verify**
   - Run `dotnet build Valt.sln`.
   - Run the relevant test class.
