# Quick Task 260806-v3s: Add color-coded thresholds to dashboard data panels

## Goal
Extend the existing dashboard row color pattern used by the Burn Rate panel (green/red) to additional DashboardData panels, adding yellow for intermediate states.

## Changes

1. **Add warning brush support**
   - Add `DashboardWarningColor` brush to `src/Valt.UI/Styles/CustomResources.axaml`.
   - Add `Warning` property to `TransactionGridResources` and initialize it in `Initialize()` and `InitializeForTesting()`.

2. **Create threshold brush helper**
   - Add `DashboardDataBrushes` static helper in `src/Valt.UI/Views/Main/Tabs/Reports/DashboardDataBrushes.cs` with methods:
     - `ForLtv(decimal)` — green <= 60, yellow <= 75, red > 75
     - `ForStackPledged(decimal)` — green <= 40, red > 40
     - `ForMayerMultiple(decimal)` — green <= 0.8, yellow < 1.2, red >= 1.2
     - `ForFearAndGreed(int)` — red <= 30, yellow <= 70, green > 70
     - `ForAthDifference(decimal)` — green abs <= 25, yellow abs <= 50, red abs > 50
     - `ForLeverage(decimal)` — green <= 30, yellow <= 70, red > 70
     - `ForYoYEvolution(decimal)` — green abs <= 15, yellow abs <= 30, red abs > 30

3. **Apply colors to panel rows**
   - `BtcLoansPanelViewModel`: Avg LTV, Highest LTV, CollateralPercent of stack.
   - `IndicatorsPanelViewModel`: Mayer Multiple, Fear & Greed.
   - `ReportsViewModel.FetchAllTimeHighDataAsync`: DeclineFromAth ("Current difference").
   - `LeveragePositionsPanelViewModel`: LeveragePercentage.
   - `ReportsViewModel.FetchStatisticsDataAsync`: MedianMonthlyExpensesEvolution, MedianMonthlyExpensesSatsEvolution.

4. **Verify**
   - Build the solution.
   - Run relevant UI tests.
