# Quick Task 260702-fx3: Restore Loan and Leverage panels in Reports tab

## Problem

After the refactor that moved leverage-position and BTC-loan dashboard logic into dedicated panel VMs (`LeveragePositionsPanelViewModel` and `BtcLoansPanelViewModel`), the Reports tab no longer displays the Loan and Leverage panels even when the user has active leveraged positions and BTC loans.

Root cause: `DashboardPanelViewModel` defaults `IsVisible` to `true`. The first time a panel refreshes and finds data, it sets `IsVisible = true`, but because the value does not change, `PropertyChanged` is not raised. `ReportsViewModel` initializes its forwarded visibility properties (`IsLeveragePositionsVisible`, `IsBtcLoansVisible`) to `false` and only learns about visibility changes through the `PropertyChanged` event, so the panels remain hidden.

## Tasks

1. **Fix default visibility**
   - File: `src/Valt.UI/Views/Main/Tabs/Reports/Panels/DashboardPanelViewModel.cs`
   - Change `_isVisible` default from `true` to `false` so that the first successful refresh raises `PropertyChanged` when it sets the panel to visible.

2. **Add regression tests**
   - File: `tests/Valt.Tests/UI/Screens/ReportsViewModelTests.cs`
   - Add tests verifying that `ReportsViewModel.Initialize()` refreshes both panel VMs.
   - Add tests verifying that panel `IsVisible` changes are forwarded to `ReportsViewModel`.
   - Add a test verifying that the panel's initial visibility is reflected in `ReportsViewModel`.

3. **Run tests**
   - Run `dotnet test --filter "FullyQualifiedName~ReportsViewModelTests|FullyQualifiedName~LeveragePositionsPanelViewModelTests|FullyQualifiedName~BtcLoansPanelViewModelTests"`.
   - Run `dotnet build Valt.sln`.

## Verification

- Loan and Leverage panels appear in the Reports tab when the user has active leveraged positions and BTC loans.
- Panels remain hidden when there is no relevant data.
- New regression tests pass.
