# Quick Task 260826-f66 Summary

## What changed

- Added `IPriceDatabaseRatesProvider` / `PriceDatabaseRatesProvider` to read the latest stored BTC/USD and per-currency fiat rates from the price database.
- `DatabaseLifecycleService.InitializePriceDatabaseAsync` now seeds `RatesState` from the price database before the first live price fetch.
- `LivePricesUpdaterJob` now:
  - publishes stored rates as a baseline before each live fetch,
  - merges live API rates with stored rates,
  - keeps stored rates for any configured currency the API does not return,
  - only marks the update as up-to-date when the API returns BTC/USD and every configured currency.
- `AccountsTotalState.CalculateCurrentWealth` no longer indexes `_ratesState.FiatRates` directly; it uses `TryGetValue` and returns `Wealth.Empty` when a required rate is missing.
- Added integration tests covering API failure fallback and partial-API-response merging.
